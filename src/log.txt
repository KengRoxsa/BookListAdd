ปัญหาของ useEffect มี 3 อันคือ 
1. การใช้งาน 3 แบบ
2. stale : อันนี้คือค่าเก่า กาเรียกฟังชันรอบแรกจะจองพื้นที่เมมที่นึง แต่ตอนเรนเดอรอบ 2 มันจะชี้ไปอีกที่
  วิธีแก้ไข ตาม ESLint จะให้เราใส่ prop เข้าไป ซึ่งใันจะมีกรณีที่มันไปผูกกับฟังชันทำให้รวน
  คีย์คือการชี้ไปที่ตำแหน่งเมมล่าสุด หรือที่ถูกต้อง อย่างใน code ของเราที่มีการใช้ bookprovider : fetchBooks
  ซึ่งถ้าเอา fn fetchBooks ไปใส่ใน useEffect ตรงๆ จะลูปเพราะ ชี้ไปที่เมมคนละตัวทั้งๆที่เป็น fn เดียวกัน
  ดังนั้นจะใช้ Callback : โดยจะไม่รันรอบ 2 บอกว่า fn ไม่เปลี่ยน ดังนั้นมันจึงจะชี้ไปที่เดิมหลังเรนเดอไป 1 รอบ
  จาก const fetchBooks =()=>{};
  const stableFetchBooks = useCallback(fetchBooks,[])
  พอมันเรนเดอรอบที่ 2 ตัวฟังชันที่ควรจะสร้างใหม่จะผผ่าน cb ซึ่งเป็น [ ] ทำให้ไปเรียกฟังชันเดิม กล่าวคือถูกสร้างแต่ไม่ได้ใช้
    เพิ่มเติม useEffect return string async/await num ไม่ได้ แต่ fn ได้นะ
